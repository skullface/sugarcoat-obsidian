# Sugarcoat, an ultra-minimal Obsidian

<img width="2448" height="1141" alt="obsidian-sugarcoat" src="https://github.com/user-attachments/assets/5d7d2697-8aef-4a1a-a142-7b542c44651b" />

I use Obsidian as a simple Markdown file editor and viewer. I don’t want most of its powerful features, so I hid them. 

> [!WARNING]
> I made this just for myself, so some features may not work how you expect!

- Fonts from Google fonts: Figtree (sans), Source Serif 4 (serif), Geist Mono (mono)
- Custom colors are included in this theme, but it really just uses the app defaults and your defined **Accent color**.
- Recommended plugin: [Shiki Highlighter](https://community.obsidian.md/plugins/shiki-highlighter) (using GitHub themes)
- Recommended settings:
  - Interface: “Show tab title bar” disable; “Show ribbon” disable
- No support included for styling plugins.
