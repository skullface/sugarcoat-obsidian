# Sugarcoat

<img width="1024" height="576" alt="screenshot" src="https://github.com/user-attachments/assets/fbfa2ca1-f3b6-4ca1-8de7-64af2c9b8ade" />

I use Obsidian as a simple Markdown file editor and viewer. I don’t want most of its powerful features, so I hid them in this ultra-minimal Obsidian theme.

## Details
- Fonts from Google fonts: Figtree (sans), Source Serif 4 (serif), Geist Mono (mono), Geist (sans)
- Custom colors are included in this theme, but it mostly uses the app default grays and your defined **Accent color**
- Recommended plugin: [Shiki Highlighter](https://community.obsidian.md/plugins/shiki-highlighter) (using GitHub themes)
- Recommended settings:
  - Interface:
    - “Show tab title bar” disable
    - “Show ribbon” disable
- No support included for styling plugins
